World Wide Web'in temel teknik bileşenlerini tanıtarak, anlamsal HTML5 mimarileri, duyarlı CSS3 stil uygulamaları ve standart web barındırma protokollerine odaklanır.

#### Ders Hakkında

Öğrenciler, modern görsel ve teknik web standartlarına uygun, erişilebilir ve kullanıcı dostu web sitelerinin planlanması, geliştirilmesi ve devreye alınması süreçlerini öğrenir.

#### Ders Bitirme Koşulları

- Derse katılım ve laboratuvar çalışmaları
- Dönem içi web geliştirme ödevleri
- Final web sitesi projesi
